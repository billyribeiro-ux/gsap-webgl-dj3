The whole course is built on Svelte 5 runes. But mid-2026 added two features that change how you load data. First, experimental await: you can now await promises at the top level of a component, inside $derived, and directly in markup — no {#await} wrapper. Second, SvelteKit remote functions: query, form, command and prerender let you call server code from anywhere in your app, fully type-safe — and query.live() streams real-time data.

1 · Remote functions — call the server from anywhere

Define server functions in a .remote.ts file. They run only on the server (so they can touch the database and secrets), but you import and call them like normal functions — SvelteKit generates the HTTP endpoint and a fetch wrapper for you, with arguments validated by a schema.

2 · Await them straight in your markup

No load function, no {#await}, no manual fetch. Await the query in the template; a <svelte:boundary> handles loading and errors. A query.live() value re-renders itself as new data streams in.

Why this matters for everything you've built. Your cinematic components need data — a gallery's items, a dashboard's live numbers, a 3D scene's config. Remote functions collapse the old load + endpoint + fetch + types dance into a single typed call, and query.live() means your D3 charts and WebGL scenes can react to real-time server data with a value that simply updates itself. The newest Svelte makes the plumbing disappear so you can spend your time on the motion.
