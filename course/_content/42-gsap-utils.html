gsap.utils is the most underrated part of GSAP. These are pure helper functions — no animation required — that solve the small numeric problems that come up constantly when you build interactive things: remapping ranges, keeping values in bounds, generating controlled randomness, snapping to steps. Learn these six and your code gets shorter and clearer everywhere.

Map a pointer to anything

Drag your pointer across the pad. Its horizontal position is remapped — once to a rotation, once to a hue — with gsap.utils.mapRange. Then Randomise picks a snapped angle and a hue from a palette. This tiny interaction uses four utils.

The essential six

  • mapRange(inMin, inMax, outMin, outMax) — the star. Returns a function that linearly remaps a value from one range to another. Pointer pixels → rotation, scroll progress → opacity, data → bar height. Everywhere.
  • clamp(min, max, value) — keep a number inside bounds. No more Math.max(0, Math.min(1, x)) noise.
  • random(min, max, snap?) or random([a, b, c]) — controlled randomness: a number in a range (optionally snapped), or a pick from a list. Perfect for organic, non-repeating motion.
  • snap(increment, value) — round to the nearest step (or to the nearest value in an array). Great for grids, ticks and magnetic sliders.
  • wrap(min, max, value) — wrap a value around a range, like a carousel index that loops from the last item back to the first.
  • interpolate(a, b) — returns a function that blends between two values — numbers, colors, even objects — by a 0–1 progress.
mapRange returns a function — reuse it. Call const toRotation = gsap.utils.mapRange(0, 1, -28, 28) once and call toRotation(t) as often as you like. You can also gsap.utils.pipe(clamp, toRotation) to compose helpers into a single transform. These are framework-agnostic plain functions — import GSAP and you can use them in your Svelte logic, your stores, anywhere.
