For this whole course we've pushed pixels on the GPU. In 2026 that same GPU runs neural networks. Transformers.js v4 (Feb 2026) loads quantized models and executes them via WebGPU — Hugging Face clocked it "faster than cloud inference, in your browser," and WebLLM runs an 8B-parameter LLM at ~70% of native speed. This is the genuine frontier of the web platform, and it's astonishingly little code.

Live demo · on-device inference

The whole pipeline is three lines

  • Load a pipeline. const classify = await pipeline('sentiment-analysis', undefined, { device: 'webgpu' }). Transformers.js fetches the model + tokenizer from the Hugging Face hub (cached after first load) and compiles it for the GPU. The task string picks the model: swap in 'image-classification', 'zero-shot-classification', 'feature-extraction' (embeddings), 'automatic-speech-recognition', even text generation.
  • Call it. await classify(text) returns [{`{ label, score }`}]. That's an actual transformer forward-pass running on your GPU — the same architecture as the big models, just small and quantized.
  • WebGPU or WASM. We request the WebGPU backend (3–10× faster) and fall back to WASM if it's unavailable. Either way it's on-device.
Why this changes the economics. One team cut a $12,000/month inference bill to zero by moving classification, autocomplete, embeddings and summarization to the client. On-device is the sweet spot for high-frequency, low-complexity AI: it's free, private (data never leaves the device), works offline, and has no network latency. Heavy reasoning still goes to a server — but a huge slice of "AI features" now belong in the browser. Pair this with everything you've built and you can ship a private, GPU-accelerated, AI-powered interface that also looks cinematic.
