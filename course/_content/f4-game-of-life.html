Conway's Game of Life is the canonical example of emergence from rules: a grid of cells, each alive or dead, updated in lockstep by four tiny rules about how many neighbours are alive. It maps onto a compute shader perfectly — the grid is a storage buffer, and one thread updates each cell by reading its eight neighbours. Cellular automata like this underpin everything from fluid lattices to procedural texture generation.

The CA pattern on the GPU

  • The grid is a buffer. One u32 per cell (0 or 1). The compute shader reads the input buffer and writes the next generation to an output buffer — never the same buffer, so every cell sees a consistent snapshot. Ping-pong, again.
  • Neighbours with wrap. Each thread counts the eight surrounding cells, wrapping at the edges with modulo so the world is a torus. Then the B3/S23 rule: a dead cell with exactly 3 neighbours is born; a live cell with 2 or 3 survives; everything else dies.
  • Render reads the buffer directly. A fragment shader maps each pixel to a cell and colours it — no CPU readback. We also throttle the simulation (stepping every third frame) so the patterns are watchable instead of a blur.
Writing into a live GPU buffer. Your cursor paints by writing 1s straight into the grid buffer with queue.writeBuffer — no shader needed for a few cells. That's the everyday bridge between CPU interaction and GPU state. Swap the four rules for different "lifelike" automata (try B36/S23, "HighLife", which has self-replicating patterns) and the same engine produces an entirely different universe.
