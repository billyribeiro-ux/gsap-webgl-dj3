A sentiment classifier was the appetizer. This is the main course: a real large language model — billions of operations per token — running as a client-side dependency. WebLLM (from the MLC team) downloads a quantized model, compiles its kernels to WebGPU, and streams a response token by token. Published benchmarks hit ~70–80% of native speed. Nothing you type leaves your machine. This is genuinely the highest level the web platform reaches in 2026.

Chat with a model on your own GPU

Click to load a small (~0.5B parameter) model — a one-time ~400 MB download, then it's cached and fully offline. Then chat. Every token is generated locally.

Live demo · an LLM in your browser

The engine in three calls

  • Create the engine. await CreateMLCEngine(modelId, {`{ initProgressCallback }`}) fetches the weights + tokenizer, caches them, and compiles the model for your GPU. The progress callback drives the loading bar — the download is the only slow part, and it happens once.
  • Stream a completion. The API mirrors OpenAI's: engine.chat.completions.create({`{ messages, stream: true }`}) returns an async iterable. We for await over it and append each token's delta.content to the live message — the same streaming UX as a cloud chatbot, with zero network.
  • It's just WebGPU underneath. Every matrix multiply in the transformer is a WebGPU compute shader — the exact technology from our particle and fluid lessons, pointed at linear algebra instead of pixels. You now understand the whole stack, top to bottom.
