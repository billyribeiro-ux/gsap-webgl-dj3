A bitmap (PNG, JPG) is a grid of coloured pixels — opaque to animation. An SVG is a document: shapes, paths and points your code can reach in and move. That's why every premium animated icon, every self-drawing signature, every morphing logo is SVG. Today we learn its anatomy and the single most useful SVG effect: draw-on.

The draw-on effect

Watch the ring and tick paint themselves. There's no library here — it's two CSS properties most developers never learn to combine.

Live demo

How it actually works

Every SVG <path>, <circle> and line has a measurable length. Two stroke properties exploit that:

  • stroke-dasharray turns a solid stroke into dashes. Set it to the path's full length and you get one dash exactly as long as the line — plus an equally long gap.
  • stroke-dashoffset slides that dash pattern along the path. Offset it by the full length and the visible dash is pushed completely off the end — the line vanishes. Animate the offset back to 0 and it draws back in.

Stagger the ring and the tick with a delay and you've choreographed a confirmation animation that feels expensive. The same technique animates signatures, maps, underlines and outline logos.

Tip: let SVG do the measuring. Add pathLength="100" to any path and the browser pretends the path is exactly 100 units long. Now stroke-dasharray: 100 always equals "the whole thing" — no JavaScript getTotalLength() needed. Perfect for responsive icons.

Where Phosphor comes in

Every icon you've seen in this course — the play triangle, the arrows, the spark in these callouts — is a Phosphor icon: clean, consistent SVG paths. Because they're SVG, you can do far more than recolour them. You can draw them on, morph between weights, or animate individual paths.
