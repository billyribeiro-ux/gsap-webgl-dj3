M6 · GSAP ScrollTrigger

Pin, Scrub & Parallax

ScrollTrigger turns the scrollbar into a timeline playhead. Pin sections, scrub animations to scroll, build parallax depth — this is the engine behind nearly every award-winning scrollytelling site.

Most "wow" moments on premium sites happen as you scroll: a product rotates, text locks in place while imagery flies past, layers drift at different speeds. All of it is ScrollTrigger — a GSAP plugin (free, like the rest) that connects any animation to the scroll position. Three ideas cover almost everything.

Scrub, parallax & pin — live

Scroll inside the panel below. The glow drifts slowly behind the content (parallax), the headline scales in lockstep with your scroll (scrub), and the card pins in place for a beat before releasing. Scroll back up and it all rewinds — because the scrollbar is the playhead.

src/lib/ScrollScene.svelte 
<script lang="ts">
  import { gsap } from 'gsap';
  import { ScrollTrigger } from 'gsap/ScrollTrigger';
  import type { Attachment } from 'svelte/attachments';

  // Register the plugin once. In a real app, do this in a shared module
  // (src/lib/gsap.ts) so it only runs a single time — see the course app.
  gsap.registerPlugin(ScrollTrigger);

  // This attachment wires three scroll-driven effects to a section:
  //   1. a pinned panel that stays put while you scroll "through" it
  //   2. layers that parallax at different speeds for depth
  //   3. a headline whose progress is *scrubbed* directly by the scrollbar
  const scrollScene: Attachment<HTMLElement> = (node) => {
    const q = gsap.utils.selector(node);
    const ctx = gsap.context(() => {
      // Parallax: background drifts slower than foreground = perceived depth.
      gsap.to(q('.bg'), {
        yPercent: -25,
        ease: 'none',
        scrollTrigger: { trigger: node, start: 'top bottom', end: 'bottom top', scrub: true }
      });

      // Scrub: tie the headline's reveal directly to scroll position. With
      // scrub:true the animation has no duration of its own — the scrollbar IS
      // the playhead, so scrolling back rewinds it.
      gsap.from(q('.headline'), {
        scale: 0.7,
        opacity: 0,
        ease: 'none',
        scrollTrigger: { trigger: node, start: 'top center', end: 'center center', scrub: true }
      });

      // Pin: freeze the card in place for one viewport of scrolling, then release.
      ScrollTrigger.create({
        trigger: q('.pin'),
        start: 'center center',
        end: '+=400',
        pin: true,
        pinSpacing: true
      });
    }, node);

    return () => ctx.revert(); // kills tweens AND their ScrollTriggers
  };
</script>

<section class="scene" {@attach scrollScene}>
  <div class="bg" aria-hidden="true"></div>
  <h2 class="headline">Scroll writes the story</h2>
  <div class="pin">Pinned while you scroll</div>
</section>

<style>
  .scene { position: relative; min-height: 220vh; display: grid; place-items: center; overflow: clip; }
  .bg { position: absolute; inset: -20% 0; background: radial-gradient(40% 40% at 50% 30%, #7c5cff55, transparent); }
  .headline { font-size: clamp(2rem, 6vw, 4rem); color: #f4f6fb; text-align: center; }
  .pin { padding: 1rem 2rem; border-radius: 14px; background: #11141f; border: 1px solid #1b2030; color: #d6dbe6; }
</style>

The three properties that matter

  • trigger + start/end — which element, and the scroll positions where the effect begins and ends. start: 'top center' reads as "when the top of the trigger hits the center of the viewport." This little grammar controls everything.
  • scrub: true — bind the animation's progress directly to scroll. No fixed duration; scroll forward to advance, back to rewind. Use a number (scrub: 1) to add a smooth catch-up lag.
  • pin: true — lock the trigger element in place while the page scrolls "through" it. This is how those sticky, full-screen story beats are built.
Always clean up your ScrollTriggers. Each one registers global scroll listeners and reserves layout space for pins. In SvelteKit, where pages mount and unmount as you navigate, orphaned triggers cause ghost scroll jumps. Our gsap.context() + ctx.revert() pattern handles this automatically — reverting a context kills the tweens and their attached ScrollTriggers in one call. (In the demo we set a custom scroller so it scrolls inside the box; in your app you'll usually omit that and use the window.)

Driving a whole timeline with scroll

The real power move: attach a ScrollTrigger to an entire timeline. Build a multi-step sequence as you learned last lesson, then add scrollTrigger: { trigger, scrub: true } to it. Now your whole choreography plays out across the scroll distance — perfect for product walkthroughs and horizontal-scroll galleries, which we tackle in the next lesson.
