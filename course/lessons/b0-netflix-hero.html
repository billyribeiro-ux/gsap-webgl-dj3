A Netflix-Grade Cinematic Hero

Everything you've learned, in one component. A streaming-grade hero: a zooming backdrop, a masked headline reveal, staggered metadata and buttons — all conducted by a single GSAP timeline. This is the payoff.

Open Netflix, Disney+ or Apple TV and the first thing you see is a hero that performs: the artwork settles in with a slow zoom, the title rises letter by letter, the metadata and buttons cascade in behind it. It feels like a title card from a film. You now have every technique to build it — let's assemble them.

The cinematic hero

Live demo · the full composition
src/lib/NetflixHero.svelte 
<script lang="ts">
  import { gsap } from 'gsap';
  import { SplitText } from 'gsap/SplitText';
  import type { Attachment } from 'svelte/attachments';

  gsap.registerPlugin(SplitText);

  type Props = {
    kicker?: string;
    title: string;
    meta?: string[];
    description: string;
  };

  let {
    kicker = 'Series',
    title,
    meta = ['2026', 'TV-MA', '1 Season', 'Sci-Fi Thriller'],
    description
  }: Props = $props();

  // The full cinematic intro: everything you learned, on ONE timeline.
  // backdrop zoom → masked headline → metadata stagger → description → buttons.
  const intro: Attachment<HTMLElement> = (node) => {
    const q = gsap.utils.selector(node);
    let split: SplitText | undefined;

    const ctx = gsap.context(() => {
      document.fonts.ready.then(() => {
        split = new SplitText(q('.hero__title'), { type: 'lines,chars', mask: 'lines' });

        const tl = gsap.timeline({ defaults: { ease: 'expo.out' } });
        tl.from(q('.hero__backdrop'), { scale: 1.25, opacity: 0, duration: 1.6, ease: 'power2.out' })
          .from(q('.hero__kicker'), { y: 16, opacity: 0, duration: 0.6 }, 0.3)
          .from(
            split!.chars,
            { yPercent: 120, opacity: 0, duration: 0.9, stagger: 0.02 },
            0.4
          )
          .from(q('.hero__meta span'), { y: 14, opacity: 0, stagger: 0.08, duration: 0.5 }, '-=0.3')
          .from(q('.hero__desc'), { y: 14, opacity: 0, duration: 0.6 }, '-=0.2')
          .from(q('.hero__actions > *'), { y: 18, opacity: 0, stagger: 0.1, duration: 0.5 }, '-=0.25');
      });
    }, node);

    return () => {
      split?.revert();
      ctx.revert();
    };
  };
</script>

<section class="hero" {@attach intro}>
  <div class="hero__backdrop" aria-hidden="true"></div>
  <div class="hero__vignette" aria-hidden="true"></div>

  <div class="hero__content">
    <p class="hero__kicker">{kicker}</p>
    <h1 class="hero__title">{title}</h1>

    <div class="hero__meta">
      {#each meta as item (item)}
        <span>{item}</span>
      {/each}
    </div>

    <p class="hero__desc">{description}</p>

    <div class="hero__actions">
      <button class="btn btn--play">▶ Play</button>
      <button class="btn btn--info">ⓘ More Info</button>
    </div>
  </div>
</section>

How the pieces combine

There's nothing new here — just composition, which is the real skill of a senior motion engineer. Every beat is something from an earlier lesson:

  • The backdrop zoom (Lesson 40) — a gsap.from with scale: 1.25 and a long, gentle power2.out. Slow, expensive-feeling, sets the mood.
  • The headline (Lesson 70) — SplitText with mask: 'lines', characters rising from behind the clip.
  • The metadata & buttons (Lessons 40 & 50) — staggered y/opacity reveals, offset on the timeline so they trail the title.
  • One timeline (Lesson 50) — every step lives on a single playhead with overlapping position parameters ('-=0.3'), so the whole intro reads as one fluid gesture, not six separate animations.
The secret is the overlap. Beginners play animations back-to-back and the result feels slow and robotic. Pros overlap them — the metadata starts before the title finishes ('-=0.3'). Your eye reads it as one continuous swell of motion. Tune those negative offsets and you tune the entire feel of the piece. That instinct, more than any API, is what separates cinematic work from the rest.

Make it yours

The component takes props — title, kicker, meta, description — so it's a real, reusable hero for your app, not a one-off. Swap the backdrop gradients for artwork, add a ScrollTrigger so the backdrop parallaxes as the user scrolls past (Lesson 60), or layer in a Threlte canvas behind it for a 3D hero. You've gone from a first hover transition to this. That's the whole journey — now go build something the studios would be proud of.
