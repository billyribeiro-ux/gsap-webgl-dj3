MotionPath & DrawSVG

Straight lines are for spreadsheets. MotionPath flies any element along a curve — banking into the turns — while DrawSVG paints the path into existence. Together they make maps, flight paths and signature animations sing.

Two more once-premium, now-free GSAP plugins. DrawSVG animates a stroke from nothing to fully drawn (the polished version of the dash trick from the SVG lesson). MotionPath moves any element — a div, an icon, an image — along an arbitrary SVG path, optionally rotating it to follow the curve. Combine them and you get the classic "route drawing itself while a vehicle travels it."

Draw the route, fly the path

The line paints itself in, then the craft travels along that exact curve, banking as it turns. It loops so you can study the motion.

Live demo · MotionPath + DrawSVG
src/lib/MotionPath.svelte 
<script lang="ts">
  import { gsap } from 'gsap';
  import { MotionPathPlugin } from 'gsap/MotionPathPlugin';
  import { DrawSVGPlugin } from 'gsap/DrawSVGPlugin';
  import type { Attachment } from 'svelte/attachments';

  gsap.registerPlugin(MotionPathPlugin, DrawSVGPlugin);

  // Two free SVG superpowers: DrawSVG animates a stroke into existence, and
  // MotionPath flies any element along an SVG path (with auto-rotation, so a
  // rocket actually banks into its turns).
  const journey: Attachment<SVGSVGElement> = (node) => {
    const q = gsap.utils.selector(node);
    const ctx = gsap.context(() => {
      const path = q('.route')[0] as SVGPathElement;
      const tl = gsap.timeline({ repeat: -1, repeatDelay: 0.8 });

      // 1. Draw the route in.
      tl.from(path, { drawSVG: '0%', duration: 1.3, ease: 'power1.inOut' })
        // 2. Fly the rocket along that exact path, rotating to follow it.
        .to(
          q('.rocket'),
          {
            duration: 2.2,
            ease: 'power1.inOut',
            motionPath: {
              path,
              align: path,
              alignOrigin: [0.5, 0.5],
              autoRotate: 90 // the rocket art points up, so offset 90°
            }
          },
          '-=0.5'
        );
    }, node);

    return () => ctx.revert();
  };
</script>

MotionPath options that matter

  • path — the curve to follow. Point it at an SVG <path> element and the motion traces it precisely; or pass an array of {`{x, y}`} points and GSAP fits a smooth curve through them.
  • align — align the moving element to the path's coordinate space so it sits on the line (essential when the element and path live in the same SVG).
  • autoRotate — rotate the element to face its direction of travel. Pass true, or a number to add an angular offset (our rocket art points up, so we offset by 90°).
DrawSVG takes from–to percentages. Animating drawSVG: '0%' with .from() reveals the whole stroke; drawSVG: '40% 60%' shows only a moving segment — perfect for a "comet tail" tracing the route, or a progress line. Pair a drawing segment with a MotionPath element riding its leading edge and you've built the animated flight maps you see in travel and delivery apps.

Real uses: onboarding flows that draw a connecting line between steps; a logo whose stroke writes itself on load; data stories where a path traces a journey across a map; playful 404 pages with a character wandering a route. MotionPath + DrawSVG are the difference between motion that goes from A to B and motion that takes you somewhere.
