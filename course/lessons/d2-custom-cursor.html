Custom Cursor & Magnetic Field

Replace the arrow with something alive: a dot that tracks instantly and a ring that trails with weight, growing and snapping to buttons while they lean toward your hand. This single interaction signals "premium" before a user reads a word.

The bespoke cursor is the calling card of high-end portfolio and agency sites. Done well it's three ideas working together: a precise dot that follows the pointer exactly, a larger ring that lags behind with inertia, and a magnetic field where interactive elements pull toward the cursor as it nears them. We scope ours to a single area so it never fights the rest of the page.

Move around — hover the targets

src/lib/CustomCursor.svelte 
<script lang="ts">
  import { prefersReducedMotion } from 'svelte/motion';

  // A bespoke cursor: a dot that tracks instantly and a ring that lags behind
  // with a lerp. Over "magnetic" targets the ring grows and snaps to the target's
  // center, while the target itself leans toward the pointer — the interaction
  // language of high-end portfolio sites. Scoped to this scene; native cursor
  // returns the moment you leave it.
  let scene: HTMLDivElement | undefined = $state();
  let dot: HTMLDivElement | undefined = $state();
  let ring: HTMLDivElement | undefined = $state();

  $effect(() => {
    if (!scene || !dot || !ring) return;
    const reduce = prefersReducedMotion.current;
    let mx = 0, my = 0, rx = 0, ry = 0;
    let hovering = false;
    let stick: { x: number; y: number } | null = null;
    let currentTarget: HTMLElement | null = null;
    let raf = 0;

    const resetTarget = () => {
      if (currentTarget) currentTarget.style.transform = '';
      currentTarget = null;
    };

    const move = (e: PointerEvent) => {
      const r = scene!.getBoundingClientRect();
      mx = e.clientX - r.left;
      my = e.clientY - r.top;
      const t = (e.target as HTMLElement).closest('.target') as HTMLElement | null;
      if (t) {
        const tr = t.getBoundingClientRect();
        const cx = tr.left - r.left + tr.width / 2;
        const cy = tr.top - r.top + tr.height / 2;
        hovering = true;
        stick = { x: cx, y: cy };
        if (currentTarget && currentTarget !== t) resetTarget();
        currentTarget = t;
        if (!reduce) t.style.transform = `translate(${(mx - cx) * 0.3}px, ${(my - cy) * 0.3}px)`;
      } else {
        hovering = false;
        stick = null;
        resetTarget();
      }
    };
    const leave = () => {
      hovering = false;
      stick = null;
      resetTarget();
    };
    scene.addEventListener('pointermove', move);
    scene.addEventListener('pointerleave', leave);

    const loop = () => {
      const tx = stick ? stick.x : mx;
      const ty = stick ? stick.y : my;
      const k = reduce ? 1 : 0.2;
      rx += (tx - rx) * k;
      ry += (ty - ry) * k;
      ring!.style.transform = `translate(${rx}px, ${ry}px) translate(-50%, -50%) scale(${hovering ? 1.9 : 1})`;
      dot!.style.transform = `translate(${mx}px, ${my}px) translate(-50%, -50%)`;
      raf = requestAnimationFrame(loop);
    };
    loop();

    return () => {
      cancelAnimationFrame(raf);
      scene!.removeEventListener('pointermove', move);
      scene!.removeEventListener('pointerleave', leave);
      resetTarget();
    };
  });
</script>

The mechanics

  • Two followers, two speeds. The dot is set to the pointer position every frame (instant). The ring eases toward it with current += (target - current) * 0.2 — that lerp is the "weight." Two elements, two follow speeds, and the cursor suddenly feels physical.
  • Snap to targets. When the pointer is over a .target, the ring's goal switches from the pointer to the target's center and it scales up — so it appears to lock onto the button. This is the "I can click this" affordance, made delightful.
  • Magnetic lean. The hovered target itself translates a fraction of the way toward the pointer ((pointer - center) * 0.3), with a springy CSS transition so it glides back on exit. Cursor and target reach for each other.
Don't hide the real cursor everywhere. Setting cursor: none globally is an accessibility and usability risk — touch users get nothing, and a laggy custom cursor on a whole page feels broken if anything stutters. Scope it to a hero or a gallery (as here), keep a fallback, and make sure keyboard focus styles are still excellent. A custom cursor is a flourish for pointer users, never a replacement for accessible interaction.

From this base you can branch endlessly: invert the cursor's colour over images with mix-blend-mode: difference, morph the ring into a "view" or "drag" label over specific elements, leave a fading trail of dots, or distort a WebGL scene at the cursor's position (you built exactly that in the distortion lesson). The cursor is a canvas of its own.
