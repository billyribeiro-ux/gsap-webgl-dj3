M2 · SVG & Phosphor Icons

Building a Living Phosphor Icon System

Icons aren't decoration — they're the smallest unit of interface motion. A bell that rings, a heart that pops, a weight that shifts on hover: this is where an interface starts to feel alive. Phosphor gives us 9,000+ icons to play with.

Phosphor is a flexible, consistent icon family — and because every icon is real SVG, you can do far more than recolor it. You can animate its paths, swap its weight (thin → regular → bold → fill → duotone) on interaction, and choreograph tiny moments of delight. In your SvelteKit app, phosphor-svelte exposes all 9,000+ as tree-shakeable components.

A living icon row

Click the heart (it pops and fills). Hover the bell (it rings), the sun (it spins), and watch the bolt pulse. Small, cheap, transform-based — and they make a UI feel crafted.

Live demo · click & hover
src/lib/IconShowcase.svelte 
<script lang="ts">
  import { Heart, BellRinging, Sun, Lightning } from 'phosphor-svelte';

  // phosphor-svelte gives you 9,000+ icons as tree-shakeable components. Because
  // they render real <svg>, you can animate them like any element — and the
  // `weight` prop lets you swap between thin/regular/bold/fill/duotone instantly.
  let liked = $state(false);
</script>

<div class="row">
  <!-- A "like" with a pop + a weight swap (outline → fill) on toggle. -->
  <button class="icon like" class:liked onclick={() => (liked = !liked)} aria-pressed={liked} aria-label="Like">
    <Heart size={30} weight={liked ? 'fill' : 'regular'} />
  </button>

  <!-- Hover to ring the bell (CSS rotation on the SVG). -->
  <span class="icon bell" aria-hidden="true"><BellRinging size={30} weight="regular" /></span>

  <!-- Hover to spin the sun. -->
  <span class="icon sun" aria-hidden="true"><Sun size={30} weight="regular" /></span>

  <!-- A pulsing accent. -->
  <span class="icon bolt" aria-hidden="true"><Lightning size={30} weight="fill" /></span>
</div>

  .row { display: flex; gap: 1rem; }
  .icon {
    width: 64px;
    height: 64px;
    display: grid;
    place-items: center;
    border-radius: 16px;
    background: #11141f;
    border: 1px solid #1b2030;
    color: #aab2c5;
    transition: color 0.3s, transform 0.4s cubic-bezier(0.34, 1.56, 0.64, 1), border-color 0.3s;
  }
  .icon:hover { color: #f4f6fb; border-color: #2a3142; }

  .like { cursor: pointer; }
  .like.liked { color: #ff5f9e; }
  .like:active { transform: scale(0.9); }
  .like.liked { animation: pop 0.4s cubic-bezier(0.34, 1.56, 0.64, 1); }
  @keyframes pop { 0% { transform: scale(1); } 40% { transform: scale(1.35); } 100% { transform: scale(1); } }

  .bell:hover :global(svg) { animation: ring 0.6s ease; transform-origin: top center; color: #19e3d6; }
  @keyframes ring { 0%,100% { transform: rotate(0); } 20% { transform: rotate(14deg); } 40% { transform: rotate(-12deg); } 60% { transform: rotate(8deg); } 80% { transform: rotate(-4deg); } }

Installing & using Phosphor in Svelte

pnpm add phosphor-svelte, then import only the icons you use:

  • import {`{ Heart, BellRinging }`} from 'phosphor-svelte'; — tree-shaken, so your bundle only ships the icons you reference.
  • Every icon takes size, color, weight and mirrored props. Drive weight from $state and you get an instant outline-to-fill toggle, like the heart.
  • Because the icon is an <svg>, you target it from your scoped styles with :global(svg) and animate it — rotate, draw-on, pulse — exactly like the bell and sun here.
Make icon motion meaningful. A bell should ring when something arrives, not at random. A heart should pop on your action. The best icon animations confirm a result or signal a state change — they're feedback, not fireworks. And as always: respect prefers-reduced-motion; a static icon is never broken, a spinning one can be nauseating.

Combine with the draw-on technique

Remember stroke draw-on from the SVG lesson? Apply it to an outline Phosphor icon and it paints itself into view — perfect for a checkmark confirming success, or a logo assembling on load. Phosphor's clean, single-path outlines are ideal subjects. Icons are where everything you've learned about SVG and CSS animation pays off at the smallest, most-used scale in your interface.
