SVG Anatomy & the Draw-On Effect

SVG is the only image format you can animate from the inside. Master its anatomy and you unlock self-drawing logos, morphing shapes, and the living icons that make Phosphor sing.

A bitmap (PNG, JPG) is a grid of coloured pixels — opaque to animation. An SVG is a document: shapes, paths and points your code can reach in and move. That's why every premium animated icon, every self-drawing signature, every morphing logo is SVG. Today we learn its anatomy and the single most useful SVG effect: draw-on.

The draw-on effect

Watch the ring and tick paint themselves. There's no library here — it's two CSS properties most developers never learn to combine.

Live demo
src/lib/DrawOn.svelte 
<script lang="ts">
  // The "draw-on" effect: an SVG stroke that paints itself into existence.
  // The trick is two properties — stroke-dasharray (the dash pattern) and
  // stroke-dashoffset (how far the pattern is pushed along the path). Set the
  // dash to the full path length and animate the offset from that length to 0,
  // and the line appears to draw.
  let { replay = 0 }: { replay?: number } = $props();
</script>

{#key replay}
  <svg class="draw" viewBox="0 0 200 200" role="img" aria-label="Animated check mark">
    <!-- The circle and tick share one timeline via staggered delays. -->
    <circle class="ring" cx="100" cy="100" r="84" fill="none" />
    <path class="tick" d="M64 104 L92 132 L140 74" fill="none" />
  </svg>
{/key}

<style>
  .draw {
    width: min(60%, 220px);
    aspect-ratio: 1;
  }

  .ring,
  .tick {
    fill: none;
    stroke-width: 6;
    stroke-linecap: round;
    stroke-linejoin: round;
  }

  .ring {
    stroke: #7c5cff;
    stroke-dasharray: 540;
    stroke-dashoffset: 540;
    animation: draw 1s cubic-bezier(0.16, 1, 0.3, 1) forwards;
  }

  .tick {
    stroke-dasharray: 130;
    stroke-dashoffset: 130;
    animation: draw 0.5s cubic-bezier(0.16, 1, 0.3, 1) 0.7s forwards;
  }

  @keyframes draw {
    to { stroke-dashoffset: 0; }
  }

  @media (prefers-reduced-motion: reduce) {
    .ring, .tick { animation: none; stroke-dashoffset: 0; }
  }
</style>

How it actually works

Every SVG <path>, <circle> and line has a measurable length. Two stroke properties exploit that:

  • stroke-dasharray turns a solid stroke into dashes. Set it to the path's full length and you get one dash exactly as long as the line — plus an equally long gap.
  • stroke-dashoffset slides that dash pattern along the path. Offset it by the full length and the visible dash is pushed completely off the end — the line vanishes. Animate the offset back to 0 and it draws back in.

Stagger the ring and the tick with a delay and you've choreographed a confirmation animation that feels expensive. The same technique animates signatures, maps, underlines and outline logos.

Tip: let SVG do the measuring. Add pathLength="100" to any path and the browser pretends the path is exactly 100 units long. Now stroke-dasharray: 100 always equals "the whole thing" — no JavaScript getTotalLength() needed. Perfect for responsive icons.

Where Phosphor comes in

Every icon you've seen in this course — the play triangle, the arrows, the spark in these callouts — is a Phosphor icon: clean, consistent SVG paths. Because they're SVG, you can do far more than recolour them. You can draw them on, morph between weights, or animate individual paths. In your SvelteKit app you'll install phosphor-svelte and get all 9,000+ icons as tree-shakeable components. We build a living icon system from them next.
