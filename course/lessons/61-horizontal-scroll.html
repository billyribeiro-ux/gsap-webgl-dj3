M6 · GSAP ScrollTrigger

Horizontal Scroll Storytelling

Scroll down, move sideways. The horizontal-scroll gallery is one of the most recognizable "premium site" effects — and it's a single ScrollTrigger that turns vertical scroll into horizontal motion.

You've seen it on Apple product pages and award-winning agency sites: a section locks in place, and as you keep scrolling down, a row of panels slides sideways. It feels exotic, but the mechanism is simple — pin the section so it stays put, then map the scroll distance to a horizontal x tween of the track.

Vertical in, horizontal out

Scroll inside the panel below. The section pins and the four cards travel left as you scroll down, then release when the last one arrives. Scroll back up and it rewinds.

src/lib/HorizontalScroll.svelte 
<script lang="ts">
  import { gsap } from 'gsap';
  import { ScrollTrigger } from 'gsap/ScrollTrigger';
  import type { Attachment } from 'svelte/attachments';

  gsap.registerPlugin(ScrollTrigger);

  const panels = ['Capture', 'Edit', 'Grade', 'Deliver'];

  // The horizontal-scroll classic: pin a section, then convert the user's VERTICAL
  // scroll into HORIZONTAL movement of a track. The page scrolls down; the gallery
  // moves sideways. Used by Apple, agencies and product tours everywhere.
  const horizontal: Attachment<HTMLElement> = (node) => {
    const ctx = gsap.context(() => {
      const track = node.querySelector('.track') as HTMLElement;
      // How far the track must travel to reveal its last panel.
      const distance = () => track.scrollWidth - node.offsetWidth;

      gsap.to(track, {
        x: () => -distance(),
        ease: 'none',
        scrollTrigger: {
          trigger: node,
          start: 'top top',
          end: () => '+=' + distance(), // scroll distance == horizontal distance
          pin: true,
          scrub: 1,
          anticipatePin: 1,
          invalidateOnRefresh: true // recompute on resize
        }
      });
    }, node);
    return () => ctx.revert();
  };
</script>

<section class="wrap" {@attach horizontal}>
  <div class="track">
    {#each panels as panel, i (panel)}
      <article class="panel" style="--i: {i}">
        <span class="num">0{i + 1}</span>
        <h3>{panel}</h3>
      </article>
    {/each}
  </div>
</section>

The three moving parts

  • Pin the section (pin: true) so it stays fixed in the viewport while the scroll happens "through" it.
  • Tween the track's x from 0 to -(scrollWidth - viewportWidth) — exactly far enough to bring the last panel into view.
  • Match the scroll length to the travel distance with end: '+=' + distance, and scrub to tie progress to the scrollbar. Now one pixel of vertical scroll equals one pixel of horizontal travel.
Make it responsive with functions. Notice x: () => -distance() and end: () => '+=' + distance() are functions, plus invalidateOnRefresh: true. On resize, ScrollTrigger re-runs them and recomputes the travel — so the effect stays correct on every screen. Hard-coding pixel values here is the #1 way horizontal scroll breaks on mobile.

You can put anything in the panels — pin a 3D Threlte canvas and rotate a product as it scrolls past, reveal text with SplitText on each panel, or stagger cards within a panel as it enters. Horizontal scroll is a stage; everything else you've learned performs on it.
