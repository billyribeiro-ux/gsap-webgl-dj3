Fluid Metaballs

Liquid blobs that merge and split like mercury — metaballs are organic-motion's greatest hit. The trick is beautiful: there are no "blobs" at all, just a continuous field with a threshold. And your cursor is part of it.

Metaballs look like soft, gooey droplets that fuse when they touch and stretch apart when they separate. The secret is that they're not objects — they're a scalar field. Every "ball" adds an inverse-square falloff to every pixel; wherever the summed field crosses a threshold, we draw liquid. Two balls near each other push the combined field over the threshold in the gap between them, so they appear to merge. Pure math, rendered per-pixel on the GPU.

Stir it with your cursor

Live demo · WebGL · move the cursor through it
src/lib/Metaballs.svelte 
<script lang="ts">
  import * as THREE from 'three';
  import type { Attachment } from 'svelte/attachments';

  // Metaballs: each "ball" contributes an inverse-square field to every pixel;
  // where the summed field crosses a threshold, we draw liquid. Because they
  // share one continuous field, blobs merge and split like mercury. All per-pixel
  // on the GPU — and your cursor is just another ball.
  const fragmentShader = /* glsl */ `
    uniform float uTime;
    uniform float uAspect;
    uniform vec2 uMouse;
    uniform float uMouseOn;
    varying vec2 vUv;

    void main(){
      vec2 uv = vUv;
      float field = 0.0;
      for (int i = 0; i < 6; i++) {
        float fi = float(i);
        vec2 c = vec2(0.5) + vec2(cos(uTime*0.6 + fi*1.7), sin(uTime*0.8 + fi*2.3)) * 0.32;
        float r = 0.07 + 0.02 * sin(uTime + fi);
        vec2 d = uv - c; d.x *= uAspect;        // correct for non-square canvas
        field += (r*r) / dot(d, d);
      }
      vec2 dm = uv - uMouse; dm.x *= uAspect;
      field += uMouseOn * 0.012 / (dot(dm, dm) + 0.0002);

      float m = smoothstep(0.95, 1.08, field);                  // the liquid surface
      vec3 inner = mix(vec3(0.486,0.360,1.0), vec3(0.098,0.890,0.839), clamp(field*0.25, 0.0, 1.0));
      vec3 col = mix(vec3(0.02,0.025,0.04), inner, m);

      float rim = smoothstep(0.86,0.97,field) * (1.0 - smoothstep(1.04,1.18,field)); // glowing edge
      col += rim * vec3(0.35,0.6,1.0) * 0.6;
      gl_FragColor = vec4(col, 1.0);
    }
  `;

  const metaballs: Attachment<HTMLCanvasElement> = (canvas) => {
    const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
    renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
    const scene = new THREE.Scene();
    const camera = new THREE.OrthographicCamera(-1, 1, 1, -1, 0, 1);
    const uniforms = {
      uTime: { value: 0 },
      uAspect: { value: 1 },
      uMouse: { value: new THREE.Vector2(0.5, 0.5) },
      uMouseOn: { value: 0 }
    };
    const material = new THREE.ShaderMaterial({
      uniforms,
      vertexShader: `varying vec2 vUv; void main(){ vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
      fragmentShader
    });
    scene.add(new THREE.Mesh(new THREE.PlaneGeometry(2, 2), material));

    let targetMouseOn = 0;
    const onMove = (e: PointerEvent) => {
      const r = canvas.getBoundingClientRect();
      uniforms.uMouse.value.set((e.clientX - r.left) / r.width, 1 - (e.clientY - r.top) / r.height);
    };
    canvas.addEventListener('pointermove', onMove);
    canvas.addEventListener('pointerenter', () => (targetMouseOn = 1));
    canvas.addEventListener('pointerleave', () => (targetMouseOn = 0));

    const resize = () => {
      renderer.setSize(canvas.clientWidth, canvas.clientHeight, false);
      uniforms.uAspect.value = canvas.clientWidth / canvas.clientHeight;
    };
    const ro = new ResizeObserver(resize);
    ro.observe(canvas);
    resize();

    let raf = 0;
    const clock = new THREE.Clock();
    const tick = () => {
      uniforms.uTime.value = clock.getElapsedTime();
      uniforms.uMouseOn.value += (targetMouseOn - uniforms.uMouseOn.value) * 0.1;
      renderer.render(scene, camera);
      raf = requestAnimationFrame(tick);
    };
    tick();

    return () => {
      cancelAnimationFrame(raf);
      ro.disconnect();
      canvas.removeEventListener('pointermove', onMove);
      material.dispose();
      renderer.dispose();
    };
  };
</script>

The field, the threshold, the rim

  • The field. For each ball at center c with radius r, add r² / distance² to the pixel's field value. Close to a ball that's huge; far away it's tiny. Sum over all balls (the cursor included) and you have one smooth landscape.
  • The threshold. smoothstep(0.95, 1.08, field) picks the surface: below it is background, above it is liquid, and the narrow band between gives a clean anti-aliased edge. Move the threshold and the blobs grow or shrink.
  • The rim glow. A second, thinner smoothstep band right at the surface adds a luminous edge — the touch that makes it read as molten metal or plasma rather than flat paint.
Mind the aspect ratio. A plane's UVs run 0→1 on both axes, so on a wide canvas your round balls become ovals. Multiply the x-component of every distance by canvasWidth / canvasHeight (a uAspect uniform) and they stay perfectly circular. This same gotcha bites every full-screen shader effect — fix it once and remember it forever.

The 2D version powers gooey menus, liquid loaders and blobby backgrounds. The exact same idea in 3D (a field sampled in a volume, surfaced with marching cubes) is how you get morphing liquid-metal sculptures. And the SVG "goo" filter (feGaussianBlur + feColorMatrix) is the no-WebGL cousin for simple cases. Threshold a field — it's one of the most reusable ideas in all of generative graphics.
