Postprocessing — Bloom & Chromatic Aberration

The difference between "a 3D model in a browser" and "a cinematic experience" is postprocessing — the full-screen grade applied after rendering. We chain bloom and chromatic aberration through Three.js's EffectComposer.

A film is colour-graded after it's shot; great 3D on the web is graded after it's rendered. Postprocessing takes the rendered frame and pushes it through a stack of full-screen shader passes before it hits the canvas. Three.js gives us EffectComposer to chain them. Two passes do most of the cinematic heavy lifting: bloom (glow) and chromatic aberration (lens colour-fringing).

Bloom + aberration

Live demo · EffectComposer pipeline
src/lib/Bloom.svelte 
<script lang="ts">
  import * as THREE from 'three';
  import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
  import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
  import { UnrealBloomPass } from 'three/addons/postprocessing/UnrealBloomPass.js';
  import { ShaderPass } from 'three/addons/postprocessing/ShaderPass.js';
  import type { Attachment } from 'svelte/attachments';

  // Postprocessing is what makes 3D look like a movie. We render the scene, then
  // push it through a chain of full-screen passes: UnrealBloom makes bright
  // pixels glow, and a custom shader adds chromatic aberration at the edges. This
  // is the "EffectComposer" pipeline every cinematic Three.js site uses.
  const ChromaticAberration = {
    uniforms: { tDiffuse: { value: null as THREE.Texture | null }, uAmount: { value: 0.004 } },
    vertexShader: `varying vec2 vUv; void main(){ vUv = uv; gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0); }`,
    fragmentShader: /* glsl */ `
      uniform sampler2D tDiffuse;
      uniform float uAmount;
      varying vec2 vUv;
      void main() {
        vec2 dir = vUv - 0.5;
        float offset = uAmount * length(dir) * 2.0;        // stronger toward the edges
        vec2 n = normalize(dir + 1e-5);
        float r = texture2D(tDiffuse, vUv + n * offset).r;
        float g = texture2D(tDiffuse, vUv).g;
        float b = texture2D(tDiffuse, vUv - n * offset).b;
        gl_FragColor = vec4(r, g, b, 1.0);
      }
    `
  };

  const pipeline: Attachment<HTMLCanvasElement> = (canvas) => {
    const renderer = new THREE.WebGLRenderer({ canvas, antialias: true });
    renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));

    const scene = new THREE.Scene();
    const camera = new THREE.PerspectiveCamera(45, 1, 0.1, 100);
    camera.position.z = 5;

    // A dark object with a bright EMISSIVE color — bloom only blooms bright pixels.
    const geo = new THREE.TorusKnotGeometry(1, 0.3, 160, 32);
    const mat = new THREE.MeshStandardMaterial({
      color: 0x05060a,
      emissive: new THREE.Color('#7c5cff'),
      emissiveIntensity: 2.2,
      metalness: 0.5,
      roughness: 0.3
    });
    const knot = new THREE.Mesh(geo, mat);
    scene.add(knot);
    scene.add(new THREE.PointLight(0x19e3d6, 40, 0, 1.6).translateX(4).translateY(3));

    // ── The composer chain ──────────────────────────────────────────────────
    const composer = new EffectComposer(renderer);
    composer.addPass(new RenderPass(scene, camera));

    const bloom = new UnrealBloomPass(new THREE.Vector2(1, 1), 1.15, 0.5, 0.0);
    composer.addPass(bloom);

    const chroma = new ShaderPass(ChromaticAberration);
    composer.addPass(chroma); // final pass → renders to the canvas

    const resize = () => {
      const w = canvas.clientWidth;
      const h = canvas.clientHeight;
      renderer.setSize(w, h, false);
      composer.setSize(w, h);
      bloom.setSize(w, h);
      camera.aspect = w / h;
      camera.updateProjectionMatrix();
    };
    const ro = new ResizeObserver(resize);
    ro.observe(canvas);
    resize();

    let raf = 0;
    const clock = new THREE.Clock();
    const tick = () => {
      const t = clock.getElapsedTime();
      knot.rotation.x = t * 0.3;
      knot.rotation.y = t * 0.4;
      mat.emissiveIntensity = 2.0 + Math.sin(t * 2.0) * 0.6; // gentle pulse
      composer.render(); // NOT renderer.render — the composer drives the chain
      raf = requestAnimationFrame(tick);
    };
    tick();

    return () => {
      cancelAnimationFrame(raf);
      ro.disconnect();
      geo.dispose();
      mat.dispose();
      composer.dispose();
      renderer.dispose();
    };
  };
</script>

The composer pipeline

A composer is an ordered list of passes. The frame flows through each in turn; the last one draws to the screen:

  • RenderPass — renders your scene into a texture (the starting frame). Always first.
  • UnrealBloomPass — finds the brightest pixels, blurs them, and adds them back, so anything emissive glows. The knot here is nearly black with a bright emissive colour, so only the glow blooms. Its key controls are strength, radius and threshold.
  • A custom ShaderPass — our chromatic-aberration shader, sampling the composited frame three times with red/blue offsets that grow toward the edges. This is how you write your own grade: any full-screen effect is just a fragment shader with a tDiffuse input (the previous pass's output).
Bloom only blooms bright pixels. The whole look depends on contrast: a dark scene with a few very bright (emissive, or HDR) elements. If you bloom an evenly-lit scene, everything turns to mush. Set a sensible threshold so only the highlights glow, and pair it with a low-key background. Same discipline as cinematography — bloom is your practical lights, not a flood. In Threlte, @threlte/extras wraps these passes as <Bloom> components so you compose the grade declaratively.

Other passes you'll reach for: depth of field (cinematic focus), film grain and vignette (texture and mood), SSAO (contact shadows for realism), and god-rays. Stack a few with restraint and a simple scene starts to look like a render from a studio.
