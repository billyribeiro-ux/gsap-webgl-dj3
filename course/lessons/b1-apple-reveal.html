An Apple-Style Product Reveal

The Apple product page is the gold standard of scroll storytelling: a product that turns and grows as captions fade through chapters, every frame welded to the scrollbar. Here's how to build one.

Open any flagship Apple product page and scroll. The device rotates, scales and settles while short lines of copy crossfade in and out — and it all tracks your scroll precisely, forward and back. It looks like an enormous production. It's actually one pinned timeline scrubbed by ScrollTrigger, built from techniques you already have.

Pin, scrub, crossfade

Scroll the panel. The product arrives, turns to show its profile as the second caption appears, then faces you for the hero line. Three "chapters," one timeline.

src/lib/AppleReveal.svelte 
<script lang="ts">
  import { gsap } from 'gsap';
  import { ScrollTrigger } from 'gsap/ScrollTrigger';
  import type { Attachment } from 'svelte/attachments';

  gsap.registerPlugin(ScrollTrigger);

  // The Apple product page move: pin the product, then scrub a single timeline so
  // it rotates and scales while captions crossfade through "chapters" — all tied
  // to scroll. One timeline + one ScrollTrigger does the whole sequence.
  const reveal: Attachment<HTMLElement> = (node) => {
    const q = gsap.utils.selector(node);
    const ctx = gsap.context(() => {
      const tl = gsap.timeline({
        defaults: { ease: 'none' },
        scrollTrigger: {
          trigger: node,
          start: 'top top',
          end: '+=2200',
          pin: true,
          scrub: 1
        }
      });

      // Chapter 1 — arrival
      tl.from(q('.product'), { scale: 0.6, autoAlpha: 0, rotateY: -40 }, 0)
        .from(q('.cap-1'), { autoAlpha: 0, y: 30 }, 0.1)
        .to(q('.cap-1'), { autoAlpha: 0, y: -30 }, 1)
        // Chapter 2 — turn to profile, second caption
        .to(q('.product'), { rotateY: 25, scale: 1.05 }, 1)
        .fromTo(q('.cap-2'), { autoAlpha: 0, y: 30 }, { autoAlpha: 1, y: 0 }, 1.1)
        .to(q('.cap-2'), { autoAlpha: 0, y: -30 }, 2)
        // Chapter 3 — hero shot, final caption
        .to(q('.product'), { rotateY: 0, scale: 1.18 }, 2)
        .fromTo(q('.cap-3'), { autoAlpha: 0, y: 30 }, { autoAlpha: 1, y: 0 }, 2.1);
    }, node);

    return () => ctx.revert();
  };
</script>

<section class="reveal" {@attach reveal}>
  <div class="stageinner">

    </div>

    <p class="cap cap-2">Every angle, considered.</p>

  </div>
</section>

The anatomy of a scroll story

  • One pinned section. pin: true holds the stage still while the user scrolls a long virtual distance (end: '+=2200'). That distance becomes your "film reel."
  • One scrubbed timeline. Everything — rotation, scale, caption crossfades — lives on a single timeline with scrub: 1. The scrollbar is the playhead, so scrolling back perfectly rewinds the story.
  • Chapters via position. We place each beat at explicit timeline positions (0, 1, 2…) so captions hand off cleanly: one fades up and out as the next fades in. That overlap is the craft.
Use autoAlpha, not opacity, for crossfades. autoAlpha animates opacity and flips visibility at the ends — so a faded-out caption can't be clicked or read by screen readers while invisible. It's a small GSAP nicety that matters for accessibility in scroll stories where many elements overlap.

Swap the placeholder product for a real <img> sequence, or — for the full effect — a Threlte 3D model whose rotation you drive from the same scrubbed timeline. Layer in SplitText for the captions and you have a page that rivals the studios. It's all composition: pin, scrub, hand off, repeat.
