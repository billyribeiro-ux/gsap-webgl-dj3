Shape Morphing

Morphing is shape-shifting: one outline flowing into a completely different one. A hamburger becoming an X, a play turning into a pause, a square melting into a heart. MorphSVG makes the impossible math trivial.

Morphing animates the actual shape of an SVG path — interpolating its points so one form smoothly becomes another. Done by hand it's brutal: two paths rarely have the same number of points, so you have to match and tween them yourself. GSAP's MorphSVG (now free) solves the matching for you, so a square can become a triangle become a plus, fluidly.

Shape shifting

Hit Morph to flow the blob through square, triangle, diamond and plus. Notice how the fill carries through the whole transformation — it's one path the entire time, just changing its d.

src/lib/MorphShapes.svelte 
<script lang="ts">
  import { gsap } from 'gsap';
  import { MorphSVGPlugin } from 'gsap/MorphSVGPlugin';

  gsap.registerPlugin(MorphSVGPlugin);

  // MorphSVG tweens one path's `d` into another's — even when they have totally
  // different numbers of points. It figures out a sensible mapping, so a square
  // can flow into a triangle into a plus. This is genuinely hard maths, made trivial.
  const shapes = [
    'M60,60 L196,60 L196,196 L60,196 Z', // square
    'M128,48 L210,196 L46,196 Z', // triangle
    'M128,44 L212,128 L128,212 L44,128 Z', // diamond
    'M104,52 L152,52 L152,104 L204,104 L204,152 L152,152 L152,204 L104,204 L104,152 L52,152 L52,104 L104,104 Z' // plus
  ];

  let i = $state(0);
  let pathEl: SVGPathElement | undefined = $state();

  // Re-run whenever `i` changes: morph the live path toward the chosen shape.
  $effect(() => {
    if (!pathEl) return;
    const tween = gsap.to(pathEl, { duration: 0.7, ease: 'power2.inOut', morphSVG: shapes[i] });
    return () => tween.kill();
  });

  function next(): void {
    i = (i + 1) % shapes.length;
  }
</script>

<svg viewBox="0 0 256 256" class="canvas" aria-hidden="true">

    <linearGradient id="grad" x1="0" y1="0" x2="1" y2="1">

    </linearGradient>
  </defs>
  <path class="shape" bind:this={pathEl} d={shapes[0]} fill="url(#grad)" />
</svg>

How to morph well

  • Target a shape or another path. morphSVG: '#otherPath' morphs into another element's outline; morphSVG: 'M…' morphs into a raw path string, as we do here.
  • Control the mapping when the auto-result looks twisty. morphSVG: { shape: '#target', shapeIndex: 3 } rotates which point maps to which, and MorphSVG even has a findShapeIndex helper to pick the cleanest one. type: 'rotational' often gives more natural results.
  • Keep complexity comparable. Morphs between shapes of similar detail read best. Wildly different point counts still work, but can look busy.
The everyday use is icon transitions. A menu icon morphing into a close icon, a play into a pause, a heart filling in — these tiny, reversible morphs are where the technique earns its keep in real products. Build them once as two path states and toggle morphSVG between them. Reach for dramatic blob-to-heart morphs sparingly, for hero moments.
