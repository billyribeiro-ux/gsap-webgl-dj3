M8 · D3 Motion

Animated Data with enter/update/exit

When the motion IS the data — bars that grow, lines that redraw, points that fly to new positions as numbers change — you want D3. Its enter/update/exit model is the most elegant idea in data visualization.

GSAP animates elements. D3 animates data. The distinction matters: with D3 you don't say "move this bar to 140px tall," you say "this bar represents the number 73," and when 73 becomes 20, D3 transitions the bar to its new height for you. Bind data to shapes, describe the transitions once, and the chart stays in sync with reality — animating every change automatically.

A self-animating bar chart

Press Shuffle. Bars smoothly grow and shrink to new values and recolor along a scale. Press Add / Remove and watch brand-new bars rise from the baseline (enter) while departing ones sink and fade (exit) — all choreographed by D3's data join.

Live demo · D3
src/lib/D3Bars.svelte 
<script lang="ts">
  import * as d3 from 'd3';

  // D3's magic isn't drawing — it's the *data join*. You bind an array to DOM
  // nodes and describe what happens to nodes that are new (enter), that persist
  // (update), or that are gone (exit). Wrap those in transitions and your chart
  // animates itself whenever the data changes. No manual tweening at all.
  let { data }: { data: number[] } = $props();

  let svgEl: SVGSVGElement | undefined = $state();
  const width = 360;
  const height = 220;

  const color = d3.scaleSequential(d3.interpolateCool);

  // This effect re-runs automatically whenever `data` changes, because it reads
  // `data` (a reactive prop). That's the bridge between Svelte's reactivity and
  // D3's imperative drawing.
  $effect(() => {
    if (!svgEl) return;
    const svg = d3.select(svgEl);

    const x = d3
      .scaleBand<number>()
      .domain(d3.range(data.length))
      .range([0, width])
      .padding(0.18);

    const max = d3.max(data) ?? 1;
    const y = d3.scaleLinear().domain([0, max]).range([height, 0]);
    color.domain([0, max]);

    const t = svg.transition().duration(750).ease(d3.easeCubicOut) as d3.Transition<
      SVGSVGElement,
      unknown,
      null,
      undefined
    >;

    svg
      .selectAll<SVGRectElement, number>('rect')
      .data(data)
      .join(
        (enter) =>
          enter
            .append('rect')
            .attr('x', (_d, i) => x(i) ?? 0)
            .attr('width', x.bandwidth())
            .attr('rx', 5)
            .attr('y', height) // new bars grow up from the baseline
            .attr('height', 0),
        (update) => update,
        (exit) => exit.transition(t).attr('y', height).attr('height', 0).remove()
      )
      .transition(t)
      .attr('x', (_d, i) => x(i) ?? 0)
      .attr('width', x.bandwidth())
      .attr('y', (d) => y(d))
      .attr('height', (d) => height - y(d))
      .attr('fill', (d) => color(d));
  });
</script>

Scales: data in, pixels out

A scale is a function mapping your data's domain to a visual range. scaleLinear().domain([0, max]).range([height, 0]) converts a value into a y-pixel (note the flipped range — SVG's y grows downward, so we invert it). scaleBand slices a width into evenly spaced, padded columns. Master scales and most of D3 falls into place; they're the grammar that keeps your visuals honest to the numbers.

The Svelte ↔ D3 bridge is one $effect. Keep your data in $state (or a prop), and put the D3 join inside an $effect that reads it. When the data changes, Svelte re-runs the effect, D3 re-joins, and the transitions play. You get Svelte's reactivity and D3's industrial-strength rendering — the best of both. Let Svelte own the data; let D3 own the SVG.

join(): the three lifecycles

selection.data(arr).join(enter, update, exit) is the heart of it. The enter function creates DOM for new data and sets its starting state (bars begin at zero height). update handles nodes that still exist. exit animates departing nodes out and removes them. Chain a shared .transition() and every one of those changes is smooth. This pattern scales from a five-bar demo to a live financial dashboard.
