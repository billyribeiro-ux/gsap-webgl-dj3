The Glitch — RGB Split, Scanlines & Datamosh

The glitch is the signature of cyberpunk, horror, and high-end tech brands — a signal tearing itself apart. We build a broadcast-grade one: RGB channel split, rolling scanlines, and random datamosh bursts that keep it from ever looking like a loop.

A convincing glitch isn't one effect — it's a stack of them firing together: the color channels separate (chromatic aberration), horizontal slices shift out of place (datamosh), scanlines roll, and the whole thing jitters. The secret that separates amateur from professional is randomness: a real broken signal is irregular, so we drive the intense bursts from a timer, not a fixed loop.

Signal lost

Hover the text to force a hard glitch, or just watch — it breaks up at random intervals on its own. Look closely and you'll see red and cyan ghosts tearing in opposite directions while scanlines crawl over the top.

src/lib/Glitch.svelte 
<script lang="ts">
  // A broadcast-grade glitch: two color-split copies of the text (red + cyan)
  // jitter independently via clip-path, scanlines roll over the top, and a
  // timer fires random "datamosh" bursts so it never looks mechanical.
  let { text = 'SYSTEM FAILURE', auto = true }: { text?: string; auto?: boolean } = $props();

  let active = $state(false);

  // Randomly intensify the glitch at irregular intervals — the key to making it
  // feel like a real signal breaking up rather than a CSS loop.
  $effect(() => {
    if (!auto) return;
    let t: ReturnType<typeof setTimeout>;
    const schedule = () => {
      t = setTimeout(
        () => {
          active = true;
          setTimeout(() => (active = false), 120 + Math.random() * 200);
          schedule();
        },
        1400 + Math.random() * 2600
      );
    };
    schedule();
    return () => clearTimeout(t);
  });
</script>

The four layers of a glitch

  1. RGB channel split. Render the text three times: the normal white copy, a red copy (::before) and a cyan copy (::after), each offset horizontally. This mimics chromatic aberration — the color fringing of a misaligned sensor. It's the single most recognizable part of the look.
  2. Datamosh slices. Each colored copy is clipped with clip-path: inset(...) to show only a horizontal band, and those bands jump to new positions on each animation step. That's the "torn into ribbons" quality. Using steps() easing makes the jumps hard and digital, not smooth.
  3. Scanlines. A repeating-linear-gradient of thin dark lines over the top, with mix-blend-mode: overlay, evokes a CRT display. Cheap, and it ties everything together.
  4. Random bursts. A timer flips an active class at irregular intervals, swapping the gentle drift for a violent shake-and-smash. This is what makes it read as a failing signal instead of a decoration.
Why data-text + content: attr(data-text)? The two colored copies have to contain the exact same text as the original. Rather than duplicate the string three times in your markup (a maintenance trap and an accessibility mess), we store it once in a data-text attribute and let the pseudo-elements pull it in with content: attr(data-text). The real text stays the only thing a screen reader sees; the ghosts are aria-hidden decoration.

Taking it further

  • Glitch on images/components by applying the same RGB-split to a duplicated element with mix-blend-mode: screen and animated clip-path — great for a logo or hero image that "corrupts" on scroll.
  • Trigger on events: fire the burst on route change, on error states, or scrubbed to scroll with ScrollTrigger for a page that destabilizes as you descend.
  • Go GPU for the real thing: in the WebGL lessons ahead, a fragment shader can displace pixels with noise and split channels per-pixel — the technique behind those liquid, full-screen glitch transitions on award sites.
Handle with care. Rapid flashing and high-contrast strobing can trigger photosensitive seizures — keep flicker subtle, never full-screen-white, and collapse the whole effect under prefers-reduced-motion (this component drops to a static color-split). A glitch should unsettle the mood, not endanger the viewer.
