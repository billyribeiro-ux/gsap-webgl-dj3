M1 · CSS Animation

Transitions & the Cinematic Hover

Before you reach for a single library, understand this: CSS transitions are GPU-accelerated, accessible by default, and can carry 80% of the motion on a premium site. Let's build a CTA people can't resist clicking.

A transition is the simplest animation there is: "when this property changes, don't snap to the new value — glide there over time." Four words define it — property, duration, easing, delay — and that's genuinely most of what you need to make an interface feel alive.

The magnetic call-to-action

Move your pointer over the button. It leans toward your cursor, a light sweep crosses its surface, and on leave it springs back. Three transitions, one tiny Svelte action — and it feels like something Stripe or Linear would ship.

src/lib/MagneticCta.svelte 
<script lang="ts">
  import type { Attachment } from 'svelte/attachments';

  // A reusable *attachment* — Svelte 5's modern replacement for actions. The
  // element leans toward the pointer, then springs back on leave. Attachments
  // run when the element mounts and return a cleanup function, so there are no
  // leaks and no onMount/onDestroy boilerplate.
  function magnetic(strength = 0.35): Attachment<HTMLElement> {
    return (node) => {
      let raf = 0;

      function move(e: PointerEvent): void {
        const r = node.getBoundingClientRect();
        // Vector from the element's centre to the pointer.
        const x = (e.clientX - (r.left + r.width / 2)) * strength;
        const y = (e.clientY - (r.top + r.height / 2)) * strength;
        cancelAnimationFrame(raf);
        raf = requestAnimationFrame(() => {
          node.style.setProperty('--mx', `${x}px`);
          node.style.setProperty('--my', `${y}px`);
        });
      }

      function reset(): void {
        cancelAnimationFrame(raf);
        node.style.setProperty('--mx', '0px');
        node.style.setProperty('--my', '0px');
      }

      node.addEventListener('pointermove', move);
      node.addEventListener('pointerleave', reset);

      // The returned function is the cleanup — Svelte calls it automatically.
      return () => {
        cancelAnimationFrame(raf);
        node.removeEventListener('pointermove', move);
        node.removeEventListener('pointerleave', reset);
      };
    };
  }
</script>

<button class="cta" {@attach magnetic(0.4)}>
  <span class="cta__label">Get started</span>
  <span class="cta__sheen" aria-hidden="true"></span>
</button>

<style>
  .cta {
    --mx: 0px;
    --my: 0px;
    position: relative;
    overflow: hidden;
    padding: 1rem 2.2rem;
    border: none;
    border-radius: 999px;
    font: 700 1.05rem/1 system-ui, sans-serif;
    color: #0a0414;
    background: linear-gradient(135deg, #7c5cff, #ff5f9e 50%, #19e3d6);
    cursor: pointer;
    /* The magnetic offset + a subtle lift, both eased. transform is GPU-cheap. */
    transform: translate(var(--mx), var(--my));
    transition: transform 0.45s cubic-bezier(0.16, 1, 0.3, 1),
                box-shadow 0.45s cubic-bezier(0.16, 1, 0.3, 1);
    box-shadow: 0 10px 30px -8px #7c5cff99;
  }

  .cta__label { position: relative; z-index: 1; }
  .cta:hover { box-shadow: 0 18px 46px -10px #7c5cffcc; }
  .cta:active { transform: translate(var(--mx), var(--my)) scale(0.97); }

  /* A light sweep that crosses the button on hover. */
  .cta__sheen {
    position: absolute;
    inset: 0;
    background: linear-gradient(110deg, transparent 30%, #ffffff66 50%, transparent 70%);
    transform: translateX(-120%);
    transition: transform 0.7s cubic-bezier(0.16, 1, 0.3, 1);
  }
  .cta:hover .cta__sheen { transform: translateX(120%); }

    .cta { transition: none; transform: none; }
    .cta__sheen { display: none; }
  }
</style>

Anatomy of the transition

The single most important line in that component is this:

transition: transform 0.45s cubic-bezier(0.16, 1, 0.3, 1);

  • transform — we animate only transform and opacity. Both are composited on the GPU, so we stay at a buttery 60fps no matter what.
  • 0.45s — long enough to read as deliberate, short enough to feel responsive. This is the "premium" pocket.
  • the cubic-bezier — our expo-out curve. Fast to react, slow to settle. It's why the spring-back feels physical, not mechanical.
Why an attachment? The pointer-tracking is imperative DOM work — exactly what {@attach} exists for. Attachments are Svelte 5's modern successor to actions: they run when the element mounts and return a cleanup function, so the listeners are removed automatically when the button leaves the page. No leaks, no onMount/onDestroy boilerplate. Because magnetic() is just a function, you can attach it — with any strength — to any element in your app.

Transition the change, not the element

A common beginner mistake is thinking "I need to animate this button." You don't. You declare how changes are eased on the element, then change whatever you like — a class, a hover state, a CSS variable — and CSS interpolates for you. That mental shift (declare the easing once, mutate freely) is what makes CSS motion so productive. GSAP, which we meet soon, takes the opposite, imperative approach — and you'll learn exactly when each one wins.
