Text Scramble / Decode

That "decrypting" text you've seen in sci-fi UIs and hacker movies — letters churning through random glyphs before snapping into the real message — is a few lines of JavaScript and a great way to draw the eye to a headline.

The scramble (or "decode") effect resolves text out of noise: each character flips through random glyphs and then locks into its final letter. It reads as computation happening — perfect for loading states, hero headlines, and anything that wants a techno-thriller edge. The craft is in the timing: stagger when each character locks so the resolve feels organic, not like a wipe.

Decode on hover

It runs once on load; hover to re-trigger. Watch individual characters settle at different moments — that randomized lock order is the whole trick.

Live demo · hover to re-decode
src/lib/Scramble.svelte 
<script lang="ts">
  import { prefersReducedMotion } from 'svelte/motion';

  // The "decode" effect: text resolves out of a storm of random glyphs, one
  // character locking into place at a time. Each slot gets a random start/end
  // frame, so the resolve looks organic rather than a clean left-to-right wipe.
  // We render per-character spans (no {@html}) so it stays XSS-safe.
  let { text = 'ACCESS GRANTED' }: { text?: string } = $props();

  type Slot = { char: string; solved: boolean };

  const GLYPHS = '!<>-_\\/[]{}—=+*^?#01ABCXYZ';
  let slots = $state<Slot[]>([]);
  let raf = 0;

  function scramble(target: string): void {
    cancelAnimationFrame(raf);

    const meta = [...target].map((to) => {
      const start = Math.floor(Math.random() * 18);
      return { to, start, end: start + 10 + Math.floor(Math.random() * 22) };
    });

    if (prefersReducedMotion.current) {
      slots = meta.map((m) => ({ char: m.to, solved: true }));
      return;
    }

    const cache: string[] = meta.map(() => ' ');
    let frame = 0;
    const tick = () => {
      let done = 0;
      slots = meta.map((m, i) => {
        if (frame >= m.end) {
          done++;
          return { char: m.to, solved: true };
        }
        if (frame >= m.start) {
          if (cache[i] === ' ' || Math.random() < 0.28) {
            cache[i] = GLYPHS[Math.floor(Math.random() * GLYPHS.length)];
          }
          return { char: cache[i], solved: false };
        }
        return { char: ' ', solved: false };
      });
      if (done === meta.length) return;
      frame++;
      raf = requestAnimationFrame(tick);
    };
    tick();
  }

  // Decode once on mount.
  $effect(() => {
    scramble(text);
    return () => cancelAnimationFrame(raf);
  });
</script>

<button class="decode" aria-label={text} onpointerenter={() => scramble(text)}>
  <span aria-hidden="true">
    {#each slots as slot, i (i)}<span class="cell" class:ghost={!slot.solved}>{slot.char}</span>{/each}
  </span>
</button>

How the resolve works

  • Per-character timelines. Each slot gets a random start and end frame. Before start it shows nothing; between the two it shows a random glyph (re-rolled ~28% of frames so it flickers); at end it locks to the real character. Randomizing those windows is what makes the decode feel alive.
  • Render per-character, not as a string. We map the slots to individual <span>s in the template instead of building an HTML string. That keeps it XSS-safe (no {@html}) and lets us dim the still-scrambling glyphs versus the locked ones — a small touch that sells the "solving" feeling.
  • One requestAnimationFrame loop advances the frame counter and stops itself the instant every slot is solved. No wasted cycles.
Accessibility first. The churning glyphs are pure decoration, so the real string lives in aria-label and the animated spans are aria-hidden. A screen reader announces "ACCESS GRANTED" instantly, while sighted users get the show. And under prefers-reduced-motion the component skips straight to the final text — no churn at all.

Pair it with the rest

Scramble shines in combination: decode a headline as it enters on scroll (ScrollTrigger), run it on a stat that's also counting up with a Tween, or fire it on every route change for a UI that feels like a terminal. Swap the glyph set to katakana for a Matrix flavor, or to your brand's character set for something custom. Small effect, enormous personality.
